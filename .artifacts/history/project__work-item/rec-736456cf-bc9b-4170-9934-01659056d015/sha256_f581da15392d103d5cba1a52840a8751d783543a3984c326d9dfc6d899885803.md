## Description

Prove the phase exit criteria hold together through `bin/aff verdict` tests.

## Approach

Run the three verify commands. Each runs pytest on `tests/test_verdict.py`, and those tests invoke `bin/aff verdict` as a subprocess.

If a named test is missing, add it in `tests/test_verdict.py` so the filter matches. Do not add a new module. Do not change `affidavit/manifest.py` or `affidavit/amendment.py` unless one of these commands shows a bug in the behavior those modules already claim.

1. `python3 -m pytest tests/test_verdict.py -q -k "pass_when or hash_mismatch or not_assertion"`
2. `python3 -m pytest tests/test_verdict.py -q -k "pass_when or hash_mismatch or bad_signature or allowlist or cwd_phase"`
3. `python3 -m pytest tests/test_verdict.py -q -k "forged_check_run"`
