## Problem

Oracle hashes cover only the test files. An agent can still earn a pass by editing `conftest.py`, fixtures, or `pytest.ini`, adding a skip elsewhere, changing the runner command, or making source detect that it runs under test.

## Approach

not yet scoped — discuss when this phase is current. Direction: the manifest freezes everything a witness depends on (declared support files, runner config, and the runner template), under the same amendment rule as oracle files. A cheap lint reports witness tests with no assertion and skips added between base and head.

## Exit criteria

Decide at plan-phase. At minimum: verdict fails a claim when a frozen support file, runner config, or runner template changed without a signed amendment, and the lint flags a no-assert witness and a new skip.
