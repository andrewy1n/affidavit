## Architecture

1. Extend `aff` CLI with `claim add` and `freeze` (and lint invocation).
2. Lint rules flag compound claims and wording that limits trust to agent-supplied input.
3. Human-signed claim: signature over claim identity/text stored in manifest; verdict verify path.
4. Tests run without orchestra/adaptive-artifacts on PATH.

## Interfaces

- `aff claim add ...`
- `aff freeze`
- Lint output stable enough for tests
- Human signature fields in manifest (shape at plan-phase)

## Decisions

- `claim-cli`: real CLI + lint + signed human claims; not JSON-only; not TUI.

## Invariants

- Standalone authoring works offline from orchestra.

## Assumptions

- Prior phases have landed freeze-related hash fields.

## Tradeoffs

- Broader CLI surface vs thin freeze-only.
- Human signatures are a different witness kind beside tests.

## Risks

- Lint false positives on compound wording. Mitigation: fixture-driven rules, keep lint advisory or blocking per plan-phase.
