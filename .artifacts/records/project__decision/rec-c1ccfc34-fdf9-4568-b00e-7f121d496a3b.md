## Rationale

The workflow-loop goal is orchestration (efforts, phases, parallel runs, discussion before planning). evidence_kind enforcement and the phase-end report are evidence features, so they belong with the new tool. Extracting first means they are built once inside the manifest and verdict design instead of built in the current structure and then ported.

## Counter-argument

Finishing evidence-kind and phase-end-evidence where they are delivers user-visible verification sooner, on code that already works, and the extraction would then move proven features instead of designing them against an interface that does not exist yet.
